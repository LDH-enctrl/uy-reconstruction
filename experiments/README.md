# Advanced / previous experiments

The four numbered folders at the repository root are the recommended entry point.

This directory preserves the earlier numerical-error investigations that motivated the current tutorial structure. In particular, the archive contains:

- fixed-range long-horizon ct-ct runs,
- same-measurement controller-error diagnostics,
- the observed block growth close to \(\rho(F)^4\),
- post-bootstrap tower-budget sweeps,
- replicated-control representation diagnostics,
- the extended run that eventually terminated with an OpenFHE approximation-error failure.

These files are intentionally separated from the beginner path. A new reader should first reproduce stages 01--04 and only then use the archive for the more detailed numerical-stability analysis.
